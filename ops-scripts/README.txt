REDOPS Set Kit — 48 ops scripts (stdlib-only, passive/public sources only)
=========================================================================
Usage: python3 <script>.py [args]   — each script prints its own Usage line.

No API keys. No dependencies beyond Python 3. Scripts only make ordinary
public HTTP(S) requests (DNS, cert transparency, archive.org, GitHub API, etc.)
and never attack, intrude, or bypass authentication.

Generate a mission pack from the REDOPS dashboard (Set Kit > Mission Pack
builder) to bundle selected scripts into one file with --list/--run/--run-all.
